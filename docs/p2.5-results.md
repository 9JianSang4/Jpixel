# P2.5 体积与启动结果

## 体积

| 产物 | 优化前 | 优化后 |
|---|---:|---:|
| 前端 JS | 147.55 KB | 111.19 KB |
| JS gzip | 52.32 KB | 42.57 KB |
| CSS | 14.34 KB | 10.13 KB |
| release exe | 3.01 MB | 3.05 MB |
| NSIS 安装包 | 1.29 MB | 1.27 MB |
| MSI 安装包 | 2.10 MB | 2.09 MB |

NSIS 安装包远低于 10 MB 目标。

## 启动

设置页不再随应用启动创建。

- 启动时只启动原生 overlay 线程、托盘和配置；
- 托盘点击“设置”时才创建 WebView2 设置窗口；
- 设置窗口关闭后隐藏，再次打开复用；
- 实测启动后 2 秒内没有 msedgewebview2 子进程；
- 空闲工作集约 30 MB。

## 本轮优化

- 删除旧 WebView 截图/贴图链路；
- 移除 `protocol-asset`；
- `image` 只启用 PNG 编码；
- 移除 `base64`、`urlencoding`、`imageproc`、`tauri-plugin-dialog`；
- 移除 `raw-window-handle` 与无用 Windows feature；
- 设置窗口按需创建。

- 托盘设置/退出

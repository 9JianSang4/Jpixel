# P2.3 贴图测试用例

## 基础

- **P301 工具栏贴图**
  - Alt+X 框选，点击工具栏“贴图”。
  - 预期：遮罩关闭，原选区附近出现无标题栏的置顶贴图窗口。

- **P302 贴图同时复制**
  - 完成 P301 后直接 Ctrl+V 到聊天/画图工具。
  - 预期：粘贴出的图像与贴图内容一致（含画笔、擦除结果）。

- **P303 双击关闭**
  - 双击贴图窗口任意位置。
  - 预期：贴图关闭，不残留白框/黑框。

- **P304 拖动**
  - 按住贴图左键拖动。
  - 预期：窗口跟随鼠标移动，不改变大小。

- **P305 Esc 关闭**
  - 单击贴图使其获得焦点，按 Esc。
  - 预期：当前贴图关闭。

## 多贴图

- **P306 同时存在多张**
  - 连续贴图 2–3 次。
  - 预期：每张独立置顶、可分别拖动、可分别双击关闭。

## 坐标/DPI

- **P307 副屏贴图**
  - 在副屏框选后贴图。
  - 预期：贴图出现在副屏原选区附近，不跑到主屏左上角。

- **P308 高 DPI**
  - 125%/150% 缩放下贴图。
  - 预期：尺寸与选区的物理像素一致，不发虚、不缩小。

## 内容

- **P309 标注内容**
  - 画几笔、橡皮擦一部分后再贴图。
  - 预期：贴图内容与复制/保存结果一致，蓝框、工具栏、十字辅助线不出现在图中。

- **P310 大图/边缘**
  - 在屏幕右下角贴图。
  - 预期：窗口位置被限制在可见区域内，不超出屏幕。

## 数量上限

- **P311 四档上限**
  - 设置 → 常规 → 贴图数量上限，分别选 4/8/16/32 张。
  - 预期：设置立即保存；重启后保留。

- **P312 超限确认气泡**
  - 贴图数量达到上限后再点贴图。
  - 预期：不立即贴图；右下角从托盘方向弹出气泡，提示再次按贴图快捷键或点击托盘图标确认。

- **P313 快捷键确认**
  - 气泡出现后，再按一次贴图快捷键。
  - 预期：关闭最早的一张贴图，创建新贴图，气泡消失。

- **P314 托盘点击确认**
  - 气泡出现后，左键点击托盘图标。
  - 预期：与 P313 相同；左键不再弹托盘菜单（菜单改为右键）。

- **P315 取消确认**
  - 气泡出现后按 Esc 或取消选区。
  - 预期：不创建贴图，气泡消失。

## 快捷键

- **P316 遮罩内贴图快捷键**
  - 设置里给“贴图”设置快捷键（默认 Ctrl+T）。
  - Alt+X 框选后按该快捷键。
  - 预期：直接贴图并复制到剪贴板，效果与点工具栏“贴图”一致。

## 动画

- **P317 气泡动画**
  - 触发 P312。
  - 预期：气泡从托盘方向上滑并淡入，约 4.5 秒后自动消失。

- **P318 画笔预览动画**
  - 鼠标移入工具栏画笔图标。
  - 预期：颜色预览块从小放大并滑入，约 160ms 完成。

# P2.3 贴图测试用例

## 基础

- **P301 工具栏贴图**
  - Alt+X 框选，点击工具栏“贴图”。
  - 预期：遮罩关闭，原选区附近出现无标题栏的置顶贴图窗口。

- **P302 贴图同时复制**
  - 完成 P301 后直接 Ctrl+V 到聊天/画图工具。
  - 预期：粘贴出的图像与贴图内容一致（含画笔、擦除结果）。

- **P303 双击关闭**
  - 双击贴图窗口任意位置。
  - 预期：贴图关闭，不残留白框/黑框。

- **P304 拖动**
  - 按住贴图左键拖动。
  - 预期：窗口跟随鼠标移动，不改变大小。

- **P305 Esc 关闭**
  - 单击贴图使其获得焦点，按 Esc。
  - 预期：当前贴图关闭。

## 多贴图

- **P306 同时存在多张**
  - 连续贴图 2–3 次。
  - 预期：每张独立置顶、可分别拖动、可分别双击关闭。

## 坐标/DPI

- **P307 副屏贴图**
  - 在副屏框选后贴图。
  - 预期：贴图出现在副屏原选区附近，不跑到主屏左上角。

- **P308 高 DPI**
  - 125%/150% 缩放下贴图。
  - 预期：尺寸与选区的物理像素一致，不发虚、不缩小。

## 内容

- **P309 标注内容**
  - 画几笔、橡皮擦一部分后再贴图。
  - 预期：贴图内容与复制/保存结果一致，蓝框、工具栏、十字辅助线不出现在图中。

- **P310 大图/边缘**
  - 在屏幕右下角贴图。
  - 预期：窗口位置被限制在可见区域内，不超出屏幕。

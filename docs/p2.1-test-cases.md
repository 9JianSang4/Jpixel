# P2.1 测试用例（骨架 + 原生截图）

> 范围：Phase 2 第一步，只做“正式模块骨架 + 原生截图主链路”。
> 不包含：工具栏、保存、画笔/橡皮、贴图、设置页改版、安装包。
> 通过标准：P0 全过；性能接近 Stage 1 spike；原产品可编译、可回退。

## 1. P2.1 交付内容

- 新增 `app/`、`core/`、`overlay/` 模块；`core` 不依赖 Tauri/窗口。
- `core`：geometry、monitor、capture、clipboard、config、hotkey、paths、logging。
- Overlay 线程：Alt+X、抓屏、遮罩、框选、复制/取消、光标限制、重按切屏。
- 托盘“截图”入口；单实例；Alt+X 默认热键。
- 保留现有设置窗口，作为过渡；设置页改版放到 P2.4。
- 旧截图路径暂时保留，确认新路径稳定后再删除（P2.2 清理）。

## 7. 单元测试清单（必须先写）

### geometry

- `normalize`：正向/反向/零宽高。
- `clamp`：四条边、四个角、完全在外。
- `min_size`：小于最小、等于最小、大于最小。
- `contains`：边界点。

### monitor

- 前台窗口属于本进程 → 用鼠标屏。
- 前台窗口是桌面/任务栏 → 用鼠标屏。
- 前台窗口是普通应用 → 用该窗口屏。
- 前台为空 → 回退主屏。
- 负坐标/主屏切换。

### hotkey

- `Alt+X`、`Ctrl+F1`、`Ctrl+Alt+J` 解析。
- 非法修饰键、缺主键、多主键。
- 大小写/空格。

### config

- 默认值、缺字段、损坏 JSON、版本迁移。
- 非法热键/颜色/宽度拒绝。
- 原子写失败不破坏旧文件（可用临时目录 + 注入失败）。

### image_ops

- 裁剪：正常/边界/零尺寸。
- 合成：尺寸一致、alpha。
- PNG 编码：可解码、尺寸正确。

## 8. 明确不在 P2.1

- 工具栏按钮、保存对话框、PNG 保存流程。
- 画笔/橡皮/撤销。

## 9. 执行顺序

1. 先写 geometry/monitor/hotkey/config 单测（红灯）。
2. 实现 core 模块，让单测变绿。
3. 接 overlay 线程 + 窗口 + 抓屏 + 选区 + 复制/取消。
4. 接托盘/单实例/Alt+X。
5. 跑 B01–B10 + H01–H03 + M01–M05 + O01–O10 + P01–P04。
6. 通过后进入 P2.2。

## 已完成

- 新增 `src-tauri/src/core/`：
  - `geometry`：纯几何 normalize/clamp/contains + 单测。
  - `hotkey`：Alt+X / Ctrl+F1 / Ctrl+Alt+J / F1–F12 解析 + 非法输入单测。
  - `config`：`NativeConfig` 默认 Alt+X、缺字段/损坏回退、原子保存 + 单测。
  - `capture`：物理像素整屏抓取，统一走 `capture_area_ignore_area_check`。
  - `clipboard`：arboard 封装（供后续 overlay 使用）。
  - `monitor`：从 spike 迁入的显示器枚举/目标屏逻辑。
- 新增 `src-tauri/src/overlay/`：
  - GDI 双缓冲、遮罩窗口、框选、复制/取消、光标限制、重按热键重抓。
  - 独立 Win32 消息循环线程；`RegisterHotKey(Alt+X)` 在窗口上注册。
- `lib.rs` 接线：
  - 启动原生 overlay 线程；托盘新增“截图”入口。
  - P2.1 过渡期停用旧的 Tauri 截图热键注册，避免和原生 Alt+X 抢占。

## 已知环境问题

- 在自动化 shell 中启动 debug `jpixel.exe` 时，Tauri/WebView2 创建主窗口偶发失败：
  - `0x800700AA`（资源被占用）或 `0x8000FFFF`（灾难性失败）。
  - 原生 overlay、托盘、热键不受影响；该错误发生在 Tauri WebView 初始化阶段。
- 该问题与 P2.1 原生路径无直接关系，但会影响“设置窗口”验收；需要单独排查 WebView2 用户数据目录/运行时。
- P2.1 过渡期设置页修改“截图热键”仍走旧命令；原生路径固定 Alt+X，P2.4 统一接管。

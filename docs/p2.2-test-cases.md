# P2.2 测试用例（工具栏 / 保存 / 标注 / UI）

> 范围：原生工具栏、保存、画笔/橡皮/撤销重做、设置页 UI 重做。
> 分支：`phase2`。P2.1 已通过；本阶段不得回归 P2.1 的截图/热键/光标限制。

| ID | P | 场景 | 预期 |
|---|---|---|---|
